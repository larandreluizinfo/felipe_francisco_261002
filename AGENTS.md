# AGENTS

## Regra obrigatória de versionamento

Toda alteração feita neste repositório DEVE ser commitada e pushada para o GitHub.

- Após qualquer criação, edição ou remoção de arquivos, execute:
  1. `git add .`
  2. `git commit -m "descrição clara da alteração"`
  3. `git push origin main`
- Nunca deixe alterações apenas locais sem push.
- Sempre verificar com `git status` se está tudo sincronizado.
